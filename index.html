    如何生成 objdump 文件

    在你自己的电脑上对编译好的产物执行 objdump，把输出保存为文本后上传：

    # Linux 下的 ELF 可执行文件（最常用）
objdump -d myapp.elf > myapp.dump

# macOS 上分析 Mach-O 可执行文件
objdump -d myapp > myapp.dump

# 交叉编译产物（用对应工具链的 objdump）
aarch64-linux-gnu-objdump -d myapp.elf > myapp.dump

# 目标文件 / 静态库也可以（注意加 -r 显示重定位）
objdump -dr main.o > main.dump

    注意：产物需要保留符号表（编译时不要加 -s / 不要 strip），否则 objdump 标注不出函数名。
